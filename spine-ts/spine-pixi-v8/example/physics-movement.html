Arrow keys / WASD: move Celeste in the container
Z / X: rotate Celeste locally
Q / E: rotate the parent normally
C / V: decrease / increase parent skew X
B / N: decrease / increase parent skew Y
Shift: move and rotate faster
Parent skew: X = 0.0°, Y = 0.0°
Inherited physics rotation: 0.0°
Parent scale: X = 1.35, Y = 0.75

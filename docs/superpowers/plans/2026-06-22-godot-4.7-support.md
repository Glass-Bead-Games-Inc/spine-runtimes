# Godot 4.7 Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make spine-godot build and run on Godot 4.7 in both the engine-module and GDExtension builds, as a multi-version addition that keeps 4.6, and add 4.7 to CI.

**Architecture:** The GDExtension targets a stable godot-cpp release (4.5) and relies on godot-cpp forward-compatibility to load in 4.6/4.7 — so the only extension-side change is the godot-cpp fallback selection in `setup-extension.sh` (this also greens the red 4.6 GDExtension CI). The module builds against Godot 4.7 source directly; engine API breakages are fixed version-agnostically (or behind `VERSION_MINOR` guards) and surfaced via CI. CI matrices gain a `4.7-stable` tier.

**Tech Stack:** C++ (Godot engine module + godot-cpp GDExtension), SCons, bash build scripts, GitHub Actions, clang-format 18.

## Global Constraints

- Keep **Godot 4.6 fully supported** — no task may regress the 4.6 module or GDExtension build.
- Prefer **version-agnostic** code that compiles on all supported versions; use `#if VERSION_MAJOR > 3 && VERSION_MINOR >= 7` (or narrower) guards only where an API genuinely diverges.
- All changed C/C++ must be **clang-format-18 clean** (the repo's `format-check-cpp` CI runs `silkeh/clang:18` with `formatters/.clang-format`). Format locally with:
  `MSYS_NO_PATHCONV=1 docker run --rm -v "D:/Workspace/spine-runtimes:/repo" -w /repo silkeh/clang:18 clang-format -i -style=file:formatters/.clang-format <files>`
- Exact engine tag for 4.7 is **`4.7-stable`**; its version string is **`4.7.stable`** (patch 0 omitted, matching how `4.6.2-stable` → `4.6.2.stable`).
- Latest stable godot-cpp release tag is **`godot-4.5-stable`**.
- Commit messages end with the project's `Co-Authored-By` trailer.
- Work happens on branch **`spine-godot-4.7-support`** (already created off `4.3`).

### Task 3: Make `SpineAtlasResource.cpp` JSON usage version-agnostic (module 4.7 robustness)

`memnew(JSON)` returns a raw pointer on ≤4.6 but a `Ref<>` on newer Godot/godot-cpp. Replace the manual `memnew`/`memdelete` with a `Ref<JSON>` + `instantiate()` so it compiles regardless. This is the one known/likely 4.7 breakage; both sites are already inside `#if VERSION_MAJOR > 3`.

**Files:**
- Modify: `spine-godot/spine_godot/SpineAtlasResource.cpp:326-333` and `:383-386`

- [ ] **Step 1: Fix the load path (parse)**

Replace:
```cpp
	JSON *json = memnew(JSON);
	error = json->parse(json_string);
	if (error != OK) {
		memdelete(json);
		return error;
	}
	Variant result = json->get_data();
	memdelete(json);
```
with:
```cpp
	Ref<JSON> json;
	json.instantiate();
	error = json->parse(json_string);
	if (error != OK) {
		return error;
	}
	Variant result = json->get_data();
```

- [ ] **Step 2: Fix the save path (stringify)**

Replace:
```cpp
	JSON *json = memnew(JSON);
	file->store_string(json->stringify(content));
	file->flush();
	memdelete(json);
```
with:
```cpp
	Ref<JSON> json;
	json.instantiate();
	file->store_string(json->stringify(content));
	file->flush();
```
